# Portafolio — Diego Torres

Sitio personal de desarrollador full stack. Una sola página con secciones de presentación, proyectos, habilidades y contacto.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lucide React (iconos)

## Desarrollo local

```bash
npm install
npm run dev
```

Abre `http://localhost:5173`.

## Personalizar contenido

Edita `src/data/portfolio.ts`:

- Email, GitHub y LinkedIn
- Textos de presentación
- Proyectos y stack
- Enlaces a demo o repos

## Build para producción

```bash
npm run build
npm run preview
```

## Desplegar

Sube el repo a GitHub y conéctalo a [Vercel](https://vercel.com) o [Netlify](https://netlify.com). Ambos detectan Vite automáticamente.

## Notas de confidencialidad

El proyecto privado aparece sin nombre comercial ni detalles del dominio de negocio. Mantén esa sección genérica hasta que puedas publicar el producto.
